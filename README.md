# questions-to-open-later

AIとの対話から生まれた問い・考察・訂正の記録。

答えだけでなく、その時点で答えられなかった問いや、
考えが変わった理由も、あとで誰かがもう一度開けるように残します。

このリポジトリには、ChatGPTやその他のAIとの対話をもとにした文章を記録します。
会話の逐語録ではなく、対話から生まれた問いや考察を整理した記録を含みます。

内容に訂正や追記を行う場合は、元の記録との違いが分かるように、
変更日と理由を残します。
